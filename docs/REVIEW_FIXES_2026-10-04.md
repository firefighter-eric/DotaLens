# 2026-10-04 审查修复与验证

本文件记录本次审查修复及发布前验证。生产地址为 https://dota-lens-ruddy.vercel.app/；生产生效情况以 PR、Vercel 部署记录及部署后检查为准。

## 安全

- 更新 Vite、React 插件、Vitest、覆盖率插件、ESLint 及受影响的传递依赖，保留原有构建工具与 React 19。
- 全量 `npm audit` 从审查时的 18 个受影响依赖节点降至 0 个已知漏洞；这不等于对应用安全性的绝对保证。
- 头像地址限制为无凭据的 HTTPS Steam CDN 地址，持久化时再次校验；头像请求不发送 referrer。
- 错误上报只发送固定事件、允许的异常类型和发布标识，不发送异常正文、堆栈或玩家信息。
- JSON 响应同时检查声明长度和流式实际字节数，上限 8 MiB；比赛分页拒绝超过 500 条的异常响应。
- 新增 `vercel.json`，与 `_headers` 保持同一安全策略，并添加配置一致性测试和 `check:deployment` 命令。

## 架构与正确性

- `App.jsx` 从约 2,000 行缩减到 673 行，拆出工作台导航、总览、账号会话、详情生命周期、目录加载、示例 ViewModel 与通用格式化。
- 核心窗口统计先显示，队友及最近对局独立补齐、单独重试。保留取消、旧请求隔离及 404/429 错误语义；核心请求失败后取消剩余补充请求。
- 重试结果按切片合并，避免后返回的其他请求覆盖已恢复的数据；缓存命中保留实际取数时间。
- 加载失败或玩家不存在时仍保留导航与本地资料库；目录加载失败、真正空目录和局部渲染失败都有独立状态与恢复入口。
- 英雄属性筛选使用稳定键，区分全才和全部属性；中英文切换保留筛选。
- 比赛时间统一使用开始时间；示例英雄通过目录 ID、头像和属性关联到比赛明细。
- 语言保存在本地，页签写入 URL hash，支持刷新及浏览器前进/后退。

## 界面与交互

- 缩短重复介绍，手机端收起次要筛选，筛选入口至少 44 px 高；增加 Steam32 获取说明。
- 资料库采用统一浅色样式，加入搜索、分类计数、排序及独立详情区；英雄支持攻击类型与定位筛选，物品支持配方筛选和分批加载。
- 英雄选择区参考 Dota 官方英雄页的肖像网格：1440 px 桌面每行 8 个小头像、390 px 手机每行 3 个；127 位英雄连续浏览，选中后在桌面侧栏或手机弹窗展示大图与属性。
- 详情支持上一个/下一个和键盘切换；关闭后恢复焦点和滚动位置。中英文切换及英雄/物品切换保留各自筛选状态。
- 限制物品图尺寸，修复统计值截断、重复清除按钮及搜索框名称随清除按钮变化的问题。
- “最菜英雄”改为“待提升英雄”；样本数量标签不再称为统计置信度。中英文文案同步更新。
- CSS 入口拆分为设计变量、组件、可访问性与工作台样式，设计变量归并为一个 `:root`。

## 验证

- 使用 Node 24.19.0 从锁文件重新 `npm ci`，无 engine 警告。
- `npm run check` 全通过：lint、115 项测试（22 个文件）、生产构建、资源预算、全量依赖审计。
- 覆盖率包含主要源码（排除静态数据、文案、测试与入口），行覆盖率 76.50%，分支覆盖率 58.08%。
- 生产包 JS 589.3 KiB / 600 KiB；首屏 JS gzip 129.8 KiB / 160 KiB。
- 浏览器验证实际 404 恢复、资料库可用、语言与页签持久化、后退、跨语言筛选、示例英雄明细和移动端抽屉。
- 最终生产构建在 1440、980、640、390 px 检查；资料库无页面级横向溢出，验证了英雄搜索、分类筛选、双语、手机详情翻页及关闭后的焦点恢复。
- CSV 内容、过滤结果及下载触发由自动化测试验证；当前内置浏览器未返回下载事件，未据此宣称文件落盘通过。
